"# ArchDraft Universal

**Professional AI-Assisted Geometry Engine & Universal CAD Pre-Processor**

ArchDraft Universal is a high-end Text-to-CAD web application that transforms natural language architectural descriptions into production-ready, industry-standard DXF files compatible with AutoCAD, Chief Architect, Revit, SketchUp, and other major CAD platforms.

## Features

- **AI-Powered Floor Plan Generation**: Convert natural language descriptions into structured JSON floor plans
- **Rigorous Spatial Validation**: Mathematical collision detection and geometric constraint enforcement
- **Professional-Grade DXF Output**: AC1015 format with proper layering, blocks, and metadata
- **Real-Time SVG Preview**: Interactive browser-based visualization before export
- **Multi-Level Support**: Automatic detection and proper Z-axis elevation handling
- **Universal CAD Compatibility**: Output designed for seamless import into any major CAD suite

## Technology Stack

- **Next.js 15** with TypeScript
- **Zod** for schema validation and spatial constraint enforcement
- **BSP Geometry Engine** for precise wall detection and opening placement
- **DXF Writer** with professional block definitions and extended entity data

## Workflow

1. Describe your building in natural language
2. Generate a structured LLM prompt
3. Feed prompt to AI (Gemini, ChatGPT, Claude)
4. Paste JSON response for validation
5. Preview geometry in browser
6. Export production-ready DXF file

---

Built for CAD professionals who demand precision, compatibility, and speed."
